## Short answer

Not fully. LeetCode runs and judges your code on its own servers, so running test cases and submitting
solutions needs an internet connection. There is no official offline mode.

You can still get a lot of useful practice done without a connection. The skill interviews test is
problem solving, not the website.

## Ways to practice coding problems offline

- **Copy problems before you go offline.** Save the problem statements you plan to work on, including
  the examples and constraints, as text or screenshots.
- **Solve in your own editor.** Write the solution in your IDE or editor and turn the examples into
  your own test cases. Add edge cases: empty input, one element, duplicates, very large values.
- **Practice on paper or a whiteboard.** Interviews often happen without autocomplete. Talk through
  your approach, write the code by hand, then trace it with a small example.
- **Work from a book.** *Cracking the Coding Interview* and similar books have hundreds of problems
  with explanations that work completely offline. Our [CTCI practice series]({{ '/ctci' | relative_url }})
  walks through it chapter by chapter.
- **Review patterns, not just problems.** Two pointers, sliding window, BFS/DFS, binary search,
  heaps and dynamic programming come up again and again. Offline time is a good time to write
  down each pattern and when to use it.
- **Submit when you are back online.** Paste your solutions into LeetCode later to check them against
  the full test suite.
